Returns every transaction receipt for a given block in a single call.

<Aside type="note">
The public Base RPC endpoints (`mainnet.base.org`, `sepolia.base.org`) now serve this method. They are rate-limited, so treat them as a convenience for testing. Production traffic belongs on a dedicated or third-party provider; see the [node providers](/node-operations/node-providers/) page.
</Aside>

<Aside type="caution">
**Flashblocks are retired.** Since [Denim](/specifications/denim-200ms-blocks/), Base seals a canonical block every 200ms. The `"pending"` tag is still accepted, but it no longer reflects Flashblocks pre-confirmation state. Ask for `"latest"` to get the newest canonical block. The [Flashblocks migration guide](/flashblocks/migrate-to-200ms-blocks/) covers the switch.
</Aside>

## Parameters

| Position | Name | Type | Description |
| --- | --- | --- | --- |
| 1 | `block` | string | Block number in hex, or `"latest"`, `"pending"`, `"safe"`, `"finalized"`, `"earliest"`. Required. |

## Returns

| Field | Type | Description |
| --- | --- | --- |
| `result` | array | Array of receipt objects, one per transaction in the block. See [`eth_getTransactionReceipt`](/api-reference/eth/eth_gettransactionreceipt/) for the receipt object shape. |

## Millisecond timestamps (Denim)

Denim is live on Base Mainnet and Base Sepolia. From Denim onward, every mined log inside a receipt can carry an optional `blockTimestampMs` field: the timestamp of the block that produced it, in milliseconds. The receipt object itself gets no new top-level millisecond field.

The field is left out when the BaseTime metadata for that block is not available. The [200ms blocks spec](/specifications/denim-200ms-blocks/#rpc) lists every method that gains these fields.

## Example

### Request

```bash
curl https://mainnet.base.org \
  -X POST -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_getBlockReceipts","params":["latest"],"id":1}'
```

### Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": [
    {
      "transactionHash": "0xabc123...",
      "blockNumber": "0x158a0e9",
      "status": "0x1",
      "gasUsed": "0x5208",
      "type": "0x2"
    }
  ]
}
```
